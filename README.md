# Appwrite Gallery

A simple image gallery application built using **Appwrite** and **vanilla JavaScript**.

## Features
- User authentication (email/password)
- Image upload to Appwrite Storage
- User-specific image gallery
- Session-protected pages

## Tech Stack
- HTML, CSS, JavaScript
- Appwrite (Auth, Database, Storage)

## Note

⚠️ Appwrite project IDs and credentials are intentionally removed from this repository.
Replace placeholder values in app.js with your own Appwrite configuration to run locally.

This project focuses on frontend Appwrite integration.
No deployment configuration is included.
